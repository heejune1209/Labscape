## Labscape
🗓️ 프로젝트 개요
- 기간 : 2024.03 ~ 2024.06
- 인원 : 3인(기획 1, 아트 1, 프로그래머 1)
- 역할 : 프로그래머
- 도구: Unity, C#, Github
- 장르 : 2D 픽셀, 횡스크롤, 러닝
- 플랫폼 : Android

## 프로젝트 설명
- Unity 엔진 기반 2D 픽셀 횡스크롤 러닝 게임
- 다양한 장애물을 파훼하며 실험실을 탈출하는 구조
- 총 3개 Stage 구성

## 주요 역할 
- UI,UX 시스템 제작
- 캐릭터 시스템 제작 및 능력치 밸런싱
- 장애물 시스템 제작 및 효과 밸런싱
- 사운드 시스템 제작 및 사운드 적용
- 로딩/업적/상점/Item 시스템 제작
